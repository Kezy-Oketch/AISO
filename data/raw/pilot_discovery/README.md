# AISO Pilot Discovery

This directory contains the original bibliographic exports used during AISO pilot corpus discovery.

## Purpose

The pilot discovery phase evaluates the retrieval strategy defined in the AISO Search and Corpus Construction Protocol v0.1 before conducting full corpus discovery for 2000–2026.

The pilot will be used to assess:

- retrieval precision;
- duplicate rates;
- source overlap;
- unique source contribution;
- geographic coverage;
- temporal coverage;
- outlet coverage;
- search-term performance; and
- potential gaps in the discovery strategy.

## Raw Data Rule

Files placed in this directory should represent original database or venue exports.

Raw files must not be manually edited.

Cleaning, normalization, deduplication, and screening should occur in downstream directories.

## File Naming Convention

Use:

`SOURCE_YYYY-MM-DD_DESCRIPTION.ext`

Examples:

`SCOPUS_2026-10-01_pilot.csv`

`WOS_2026-10-01_pilot.txt`

`OPENALEX_2026-10-01_pilot.json`

## Licensing

Some bibliographic database exports may be subject to licensing or redistribution restrictions.

Restricted raw exports should remain private and should not be included in a public AISO release unless redistribution is permitted.
